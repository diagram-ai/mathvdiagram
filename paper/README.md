# paper/

Publication assets generated by
`python -m mathvdiagram.benchmark.paper_figures`.

| Subdir | Contents |
|--------|----------|
| `figures/` | PDF figures (distributions, compile rates, category heatmap, correlations, significance, difficulty, radar, scatter). |
| `tables/` | LaTeX tables (`tab1_leaderboard_all.tex`, `tab1_leaderboard_common.tex`, `tab2_categories.tex`). |
| `data/` | Flat exports for reproducibility (`full_results.csv`, `common_subset.csv`, `summary_stats.json`). |
| `reports/` | Rendered HTML reports (tracked via Git LFS). |

Regenerate everything after a run:

```bash
python -m mathvdiagram.benchmark.paper_figures --outputs-dir outputs --paper-dir paper
```

Large binary assets (PDFs, PNGs, HTML reports) are tracked with Git LFS; see
[`.gitattributes`](../.gitattributes).
